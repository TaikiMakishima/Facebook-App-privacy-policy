プライバシーポリシー・データの削除について

当社が運用する Facebook ページ自動投稿アプリケーション（以下「本アプリ」）に関する取り扱いを定めます。 Meta for Developers アプリ公開に伴う開示用ページです。

最終更新日: 2026年10月13日

プライバシーポリシー データの削除手順 お問い合わせ

1. プライバシーポリシー

1.1 事業者情報

  • 事業者名: シャキント合同会社
  • 連絡先: contact@shakint.co.jp

1.2 本アプリの目的

本アプリは、当社 Facebook ページ「シャキント合同会社」への定型投稿および関連コメント投稿を自動化するために利用します。 一般ユーザー向けのソーシャルログインサービスや、不特定多数の個人データを収集するサービスではありません。

1.3 取得・利用する情報

  • Facebook Graph API 利用のための Page Access Token 等の認証情報
  • 投稿文・コメント文・投稿先ページIDなど、自動投稿の実行に必要な業務データ
  • 運用確認用の通知先（LINE 等）に関する設定情報

本アプリは、上記を自動投稿および運用確認の目的にのみ利用します。販売・広告配信・無関係な第三者提供は行いません。

1.4 保管場所・保管方法

  • Google スプレッドシート（投稿下書き・運用管理）
  • Google Apps Script のスクリプトプロパティ（トークン等の秘密情報）

秘密情報はスプレッドシート本文への平文記載を避け、スクリプトプロパティ等で管理します。

1.5 第三者提供

投稿処理のため、Meta（Facebook）および Google（スプレッドシート / Apps Script）の各サービスへ、必要な範囲でデータを送信します。 各サービスの取り扱いについては、各社の規約・ポリシーに従います。

1.6 保管期間

自動投稿の運用に必要な期間、データを保管します。運用終了または削除依頼があった場合は、合理的な期間内に削除または利用停止します。

1.7 改定

本ポリシーは必要に応じて改定します。重要な変更がある場合は、本ページの更新日を改定します。

2. データの削除手順

Meta アプリ設定における「ユーザーデータの削除」説明として、以下の手順を定めます。

本アプリは自社ページ運用用です。削除依頼は、当社連絡先へのメールで受け付けます。

2.1 削除を依頼できる内容（例）

  • Facebook Page Access Token 等の認証情報の削除
  • 自動投稿・確認通知の停止
  • 本アプリ連携に関する設定データの削除

2.2 依頼方法

  1. contact@shakint.co.jp にメールを送信してください。
  2. 件名例: 【FB自動投稿】データ削除依頼
  3. 本文に、削除希望の内容（トークン削除 / 自動投稿停止 など）と連絡可能なメールアドレスを記載してください。

2.3 対応内容

  • 受領後、本人確認に必要な範囲で確認のうえ対応します
  • スクリプトプロパティ上のトークン削除、トリガー停止、関連設定の削除または無効化を行います
  • 対応完了後、依頼元メールアドレスへ結果を通知します

2.4 対応期間の目安

原則として、依頼受領から 30 日以内に対応します。
